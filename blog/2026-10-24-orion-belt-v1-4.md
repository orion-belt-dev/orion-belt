**Orion Belt 1.4.0** takes the outbound-agent model beyond SSH. RDP, VNC and
`kubectl` now go through the same agents that dial out to the gateway, with
the same request, approve and expire flow and the same audit trail.

{/* truncate */}

## RDP and VNC

`osh rdp win-01` and `osh vnc lab-02` open a local port relayed to the
machine through its agent; point any RDP or VNC client at it. Plain
`ssh -N -L 13389:win-01:3389 alice@gateway` works too. Grants use the new
`rdp` and `vnc` access types, and the agent decides where each protocol goes,
so the gateway can never steer it at an arbitrary host. See
[RDP and VNC](/docs/guides/rdp-vnc).

## Just-in-time Kubernetes access

An approved `k8s` grant, scoped as `payments/edit` or `*/view`, becomes a
real RoleBinding or ClusterRoleBinding for `orion:<user>`, issued by an agent
running inside the cluster. `osh kube prod-eu` writes a credential-free
kubeconfig and relays kubectl as that user, so Kubernetes RBAC enforces
exactly the grant. Bindings are reconciled against grants continuously,
survive gateway restarts, and are deleted by the agent itself when they
expire, even if the gateway is unreachable. See
[Kubernetes](/docs/guides/kubernetes).

## Compliance and access intelligence

- [Compliance reports](/docs/guides/compliance-reports): SOC 2 access,
  ISO 27001 access review and PCI admin activity, as CSV, PDF or JSON. They
  include RDP, VNC and kubectl connections.
- [Risk signals, access explain and anomaly flags](/docs/guides/risk-and-anomalies):
  every request records who, from where and how; a risk policy can escalate
  or auto-approve; `osh explain` says why access is allowed or denied; and
  unusual sessions are flagged for review.

## Upgrade notes

- `both` grants now cover `ssh` and `scp` only. Before 1.4.0 the permission
  check matched `both` for any access type; with tunnel and Kubernetes types
  added, that would have widened every existing SSH grant.
- Agents must be on 1.4.0 for RDP, VNC and Kubernetes. Older agents keep
  working for SSH and are told to upgrade if a tunnel is requested.
