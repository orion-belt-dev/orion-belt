API Endpoints

Every path below is relative to the server's HTTP address, for example https://orion.example.com. The full request and response schemas are in the OpenAPI document the server serves at /api/v1/openapi.yaml (and /api/v1/openapi.json).

AccessMeaning
PublicNo credentials; rate-limited per IP
UserAny signed-in user: Authorization: Bearer <API key or JWT>, or the console session cookie
AdminRole admin or operator

Errors use one body format; see Errors.

Server​

MethodPathAccessDescription
GET/healthPublicLiveness check
GET/api/v1/versionPublicVersion, commit and build date
GET/api/v1/gateway-infoPublicPublic URL and SSH address agents and clients use
GET/api/v1/openapi.yaml, /api/v1/openapi.jsonPublicOpenAPI document
GET/metricsPublicPrometheus metrics, when enabled

Sign-in and registration​

MethodPathAccessDescription
POST/api/v1/public/auth/challengePublicChallenge to sign with your SSH key
POST/api/v1/public/login/keyPublicSign in with a signed challenge; returns an API key
POST/api/v1/public/login/tokenPublicSign in and get a JWT
POST/api/v1/public/login/passwordPublicSign in with password (and TOTP when enrolled)
POST/api/v1/public/loginPublicSign in with your SSH key; returns a session and an optional JWT
POST/api/v1/public/webauthn/login/begin, …/finishPublicSign in with a security key
POST/api/v1/public/auth/browser-bootstrap/redeemPublicRedeem a one-time console sign-in code (osh login)
POST/api/v1/public/register/agentAdminRegister an agent's public key (public path kept for old scripts; needs admin or operator credentials)
POST/api/v1/public/register/clientAdminCreate a user with a public key; anonymous only for the very first account, which becomes admin
POST/api/v1/logoutUserEnd the current session
GET/api/v1/auth/meUserThe signed-in user
POST/api/v1/auth/browser-bootstrapUserIssue a one-time console sign-in code
POST, DELETE/api/v1/auth/passwordUserSet or remove your password

GET, POST/api/v1/ssh-keysUserList or add SSH public keys

GET/api/v1/mfa/statusUserTOTP enrollment status
POST/api/v1/mfa/enroll, /api/v1/mfa/confirm, /api/v1/mfa/disableUserEnroll, confirm or disable TOTP

GET/api/v1/webauthn/credentialsUserList security keys
DELETE/api/v1/webauthn/credentials/{id}UserRemove a security key
GET/api/v1/ssh-cert/caUserThe user CA's public key

PUT, DELETE/api/v1/admin/machines/{id}AdminUpdate or delete a machine

Agents​

GET/api/v1/admin/agents/connectedAdminAgents connected now
POST/api/v1/admin/agents/install-scriptAdminRegister a machine and generate its install script

POST/api/v1/admin/agents/{machine_id}/disconnectAdminDrop an agent's connection

POST/api/v1/admin/access-requests/{id}/approve, …/rejectAdminApprove or reject a request
GET, PUT/api/v1/admin/risk-policyAdminRisk-based auto-approve and escalate rules
